# Data Structures & Algorithms in C++

A comprehensive, production-grade implementation library of core data structures and algorithmic paradigms from scratch using modern object-oriented C++.

This repository serves as a rigorous self-study track focused on low-level memory management, explicit pointer manipulation, structural runtime complexities ($\mathcal{O}$ notation), and defensive software engineering principles.

---

## System Architecture & Roadmap

The codebase is strictly modularized to separate foundational language mechanics, clean data structure blueprints, and algorithmic problem-solving tasks.

```text
DSA-with-cpp/
├── 01-cpp-essentials/      # Pointers, references, memory allocation, and structures
├── 02-recursions/          # Stack execution tracing, mathematical paradigms
├── 03-arrays/              # Sequential allocation, dynamic resizing mechanics
├── 04-strings/             # Custom string class, character-level operations
├── 05-matrices/            # 2D array structures, matrix operations
├── 06-linked-list/         # Linear non-contiguous memory structures
├── 07-stacks/              # LIFO structures, parenthesis matching
├── 08-queues/              # FIFO structures, queue via two stacks
├── 09-trees/               # All about trees, Binary trees, AVL, Red-Black trees and more
├── 10-heap/                # Heap structures, heapify implementation
├── 11-sorting-techniques/  # Shell sort and other various sorting algorithms
├── 12-hashing-techniques/  # Hash tables, DFS-based algorithms
├── 13-algorithm-strategies/# general strategies
├── libraries/              # Standalone, documented libraries (Array, MyString, etc.) with README + LICENSE
└── leetcode/               # Algorithmic sandbox for competitive programming puzzles
```
